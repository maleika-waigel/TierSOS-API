# TierSOS-API
TierSOS ist eine REST-API zur Suche nach geeigneten Tierarztpraxen und tierärztlichen Notdiensten. Mit Standortsuche, Tierartenfilter und persönlichen Haustierprofilen soll sie Tierhaltern helfen, schnell passende tierärztliche Hilfe in ihrer Umgebung zu finden. Entwickelt mit Python und FastAPI.
